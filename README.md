# NeuroNote｜類神經網路知識庫

NeuroNote 是一個以初學者為對象的類神經網路學習網站，使用原生 HTML、CSS、JavaScript 製作，並可透過 GitHub Pages 公開。

## 專案特色
- 深色科技風介面
- 類神經網路主題知識卡
- 即時搜尋與分類篩選
- 響應式網頁設計
- 以 `AGENTS.md` 定義 AI 後續開發規則

## 本機預覽
直接以瀏覽器開啟 `index.html`，或使用 VS Code Live Server。

## GitHub Pages 部署
1. 建立 GitHub repository，例如 `neuronote`。
2. 將本專案所有檔案上傳至 repository 根目錄。
3. 進入 **Settings → Pages**。
4. Source 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待部署完成，網址通常為 `https://你的帳號.github.io/neuronote/`。

## AI 開發規範
請先閱讀根目錄的 `AGENTS.md`，再新增或修改頁面。
